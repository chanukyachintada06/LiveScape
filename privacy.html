LiveScape Privacy Policy

LiveScape is a browser extension that customizes the New Tab experience with live wallpapers, widgets, and shortcuts.

Data Collection

LiveScape does not collect or transmit personal user data to external servers.

The extension only stores user preferences locally using the browser's local storage.

This includes:

  • wallpaper selections
  • widget layout positions
  • shortcut links
  • appearance settings

These settings are stored locally on the user's device using chrome.storage.local.

Location Access

If the Weather Widget is enabled, the extension may request the user's approximate location through the browser's geolocation API to display local weather information.

Location data is never stored or transmitted to any server other than the weather API request required to retrieve weather data.

Third-Party Services

LiveScape may interact with the following third-party services:

  • Open-Meteo Weather API (weather data)
  • Google Favicon Service (website icons)

These services are used solely to display content within the extension.

Data Sharing

LiveScape does not sell, share, or transfer any personal data.

Changes to This Policy

This privacy policy may be updated as the extension evolves.

Contact

For questions or concerns regarding this privacy policy, please contact the developer through the project's GitHub repository.
