# Wallpapers Directory

Place your video and GIF wallpaper files here.

## Supported formats:
- **Video**: MP4, WebM (recommended: 1920x1080, <50MB)
- **GIF**: Animated GIF files (<20MB)

## Usage:
Upload wallpapers directly through the LiveScape settings panel
in your browser's New Tab page. Files are stored in browser
local storage as base64 data URLs.

## Tips:
- Use compressed video files for best performance
- WebM format offers better compression than MP4
- Keep GIFs under 10MB for smooth playback
